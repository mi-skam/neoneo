# neoneo

The Neo2 keyboard layout for macOS, rebuilt so Option, Command and Control
behave as on every macOS layout: a generated keylayout plus a small set of
Karabiner-Elements rules, with Mod3/Mod4 signalled through the Caps Lock state.
Work in progress; see [the design](docs/superpowers/specs/2026-11-16-neoneo-design.md)
and [the macOS quirks](docs/quirks.md).
